# 📊 Customer Churn Prediction

## Overview

This project predicts whether a customer is likely to leave a bank or continue using its services based on customer demographics and account information.

## Dataset

* Bank Customer Churn Dataset
* Total Records: 10,000
* Features: Customer demographics, account details, and banking activity.

## Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Scikit-learn
* Joblib

## Machine Learning Workflow

1. Data Loading
2. Data Preprocessing
3. Feature Encoding
4. Feature Scaling
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Model Comparison
9. Model Saving

## Models Implemented

### Logistic Regression

Accuracy: 81.10%

### Random Forest

Accuracy: 86.65%

### Gradient Boosting

Accuracy: 86.75%

## Model Comparison

| Model               | Accuracy |
| ------------------- | -------- |
| Logistic Regression | 81.10%   |
| Random Forest       | 86.65%   |
| Gradient Boosting   | 86.75%   |

## Best Model

Gradient Boosting achieved the highest accuracy of 86.75% and was selected as the final model.

## Conclusion

This project successfully predicts customer churn using machine learning techniques. Among all models tested, Gradient Boosting achieved the best performance and was selected as the final prediction model.
