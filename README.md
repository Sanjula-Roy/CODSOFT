# CODSOFT Machine Learning Internship

This repository contains the Machine Learning projects completed during the CodSoft Machine Learning Internship.

## Projects

### Task 1: Movie Genre Classification

Predicts the genre of a movie based on its plot summary using Natural Language Processing (NLP) and Machine Learning.

**Technologies Used**

* Python
* Pandas
* Scikit-learn
* TF-IDF
* Logistic Regression
* Naive Bayes
* Support Vector Machine (SVM)

**Best Result**

* Logistic Regression Accuracy: **57.99%**

---

### Task 2: Customer Churn Prediction

Predicts whether a customer is likely to leave a bank using customer demographic and account information.

**Technologies Used**

* Python
* Pandas
* Scikit-learn
* Logistic Regression
* Random Forest
* Gradient Boosting

**Best Result**

* Gradient Boosting Accuracy: **86.75%**

---

### Task 3: Spam SMS Detection

Classifies SMS messages as Spam or Ham using Machine Learning and text processing techniques.

**Technologies Used**

* Python
* Pandas
* Scikit-learn
* TF-IDF
* Logistic Regression
* Naive Bayes
* Support Vector Machine (SVM)

**Best Result**

* Naive Bayes Accuracy: **97.49%**
