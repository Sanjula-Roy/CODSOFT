# Task 3: Spam SMS Detection

This project classifies SMS messages as Spam or Ham using Machine Learning.

## Dataset
SMS Spam Collection Dataset (UCI/Kaggle)

## Technologies Used
- Python
- Google Colab
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression
- Naive Bayes
- Support Vector Machine (SVM)

## Results
- Logistic Regression Accuracy: 94.89%
- Naive Bayes Accuracy: 97.49%
- SVM Accuracy: 97.40%

Best Model: Naive Bayes

## Conclusion
The Naive Bayes model achieved the highest accuracy of 97.49% and was selected as the final model for spam detection.
